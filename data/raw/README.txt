Raw BMS telemetry used in this study is proprietary and is not distributed with this public repository.

The repository therefore supports reproduction of the released downstream analyses and figures from the included aggregate result artifacts, but it does not provide end-to-end reproduction of dataset construction, policy training, or evaluator fitting from the original telemetry.

For authorized users with access to the source dataset:
1. Place exactly one original BMS data file in this directory.
2. Supported formats are CSV, XLSX, XLSM, and XLS.
3. Do not modify the original source file.
4. Do not place derived spreadsheets in this directory.

Raw BMS files in the supported formats are excluded from Git tracking by the repository .gitignore.
